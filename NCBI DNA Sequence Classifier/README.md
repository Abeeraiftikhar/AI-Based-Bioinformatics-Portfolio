# 🧬 NCBI DNA Sequence Classifier

A machine learning–based bioinformatics project for classifying DNA sequences into **promoter** and **non-promoter** regions using k-mer features and Random Forest.

## 🚀 Project Overview

This project processes real FASTA DNA sequences and builds a complete ML pipeline for genomic classification. It is designed for bioinformatics research and educational use.

## 🧪 Features

- Load DNA sequences from FASTA files
- K-mer based feature extraction
- Machine Learning model (Random Forest)
- Promoter vs Non-Promoter classification
- Batch prediction support
- CSV export of results
- Data visualization of predictions

## 🧬 Technologies Used

- Python  
- BioPython  
- Pandas  
- Scikit-learn  
- Matplotlib

## 📊 Workflow

1. Load FASTA sequences  
2. Extract k-mer features  
3. Convert sequences into numerical vectors  
4. Train ML model  
5. Predict promoter/non-promoter  
6. Export results to CSV  
7. Visualize outputs
